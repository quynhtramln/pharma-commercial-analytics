# Interactive HTML Dashboard

> Built on **synthetic** data - all names and figures are fictitious.

Browser version of the Power BI report, for reviewers without Power BI Desktop.
Deployed automatically to **GitHub Pages** by [`.github/workflows/deploy-dashboard.yml`](../.github/workflows/deploy-dashboard.yml)
on every push to `main` that touches this folder.

- Entry point: `index.html` (must be named `index.html` for Pages)
- Keep all CSS/JS inline or in this folder; external libraries from a CDN are fine.
- Figures are the same as the Power BI report (reconciled in [docs/07](../docs/07_validation_and_next_steps.md)).
